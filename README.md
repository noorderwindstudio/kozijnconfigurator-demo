# Kozijnenconfigurator – demo

Klikbaar prototype van een kozijnenconfigurator (Noorderwind Studio / noorderwind.app).

Live: https://noorderwindstudio.github.io/kozijnconfigurator-demo/

Dit is een demo: alle prijzen zijn voorbeeldprijzen, er zit geen server achter en aanvragen/instellingen worden alleen lokaal in de browser bewaard.
